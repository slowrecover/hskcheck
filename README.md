# hskcheck

Source for [hskcheck.com](https://hskcheck.com): a free HSK 3.0 level checker. Paste Chinese text and see which words are above a learner's level.

- `index.html` — the whole site: page, styles, word lists and checker logic in one file
- Word lists: New HSK (HSK 3.0) 2025 syllabus, Levels 1–3 (1,000 words), cross-checked against a second published list
- Hosted on GitHub Pages; `CNAME` points the site to hskcheck.com
