ฝึกเขียนตัวอักษร YCT 3

พิมพ์แบบฝึกคัดตัวอักษรจีนของคำศัพท์ระดับนี้ได้ฟรี มีลำดับขีด พินอิน และช่องให้เขียนตามบนตาราง 田

พิมพ์แบบฝึกเขียนแบบฝึกหัดคำศัพท์YCT ทุกระดับ

เกี่ยวกับ YCT 3

YCT 3 เพิ่มคำศัพท์เป็นสองเท่า รวมเป็น 300 คำ ผู้เรียนเริ่มเล่าเรื่องในแต่ละวัน โรงเรียน กีฬา สุขภาพ การซื้อของ และสภาพอากาศได้ และให้เหตุผลง่าย ๆ ด้วย 因为 และ 所以

คำไวยากรณ์ใหม่ในระดับนี้ได้แก่ 把 过 得 และ 吧

ที่มา คำศัพท์และพินอินเป็นไปตามหลักสูตร YCT ระดับ 3 อย่างเป็นทางการ (新中小学生汉语考试 YCT 大纲) และตรวจทานกับสำเนารายการที่เผยแพร่อย่างอิสระอีกหนึ่งแหล่ง เรียงตามลำดับตัวอักษรของพินอิน
