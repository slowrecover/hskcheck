ชื่อ วันที่

Aเลือก 跟 一起 หรือ 谁

เติม 跟 一起 หรือ 谁 ในช่องว่าง คำแปลภาษาไทยบอกความหมายของประโยค

  1. 我姐姐一起去医院。（跟 / 一起 / 谁）ฉันจะไปโรงพยาบาลกับพี่สาว
  2. 我们去吃饭吧。（跟 / 一起 / 谁）ไปกินข้าวด้วยกันเถอะ
  3. 你跟一起学习？（跟 / 一起 / 谁）คุณเรียนหนังสือกับใคร
  4. 她每天跟姐姐走路去学校。（跟 / 一起 / 谁）เธอเดินไปโรงเรียนกับพี่สาวทุกวัน
  5. 明天你想我们一起去看电影吗？（跟 / 一起 / 谁）พรุ่งนี้คุณอยากไปดูหนังกับพวกเราไหม
  6. 你跟一起去商店了？（跟 / 一起 / 谁）คุณไปร้านค้ากับใครมา
  7. 我不想跟他玩。（跟 / 一起 / 谁）ฉันไม่อยากเล่นกับเขา
  8. 爸爸没有我们一起回家。（跟 / 一起 / 谁）พ่อไม่ได้กลับบ้านพร้อมกับพวกเรา

Bเรียงคำให้เป็นประโยค

เขียนคำทั้งหมดให้เป็นประโยคที่ถูกต้องหนึ่งประโยค

  1. 一起我跟去你ฉันจะไปกับคุณ
  2. 哥哥一起跟他打篮球เขาเล่นบาสเกตบอลกับพี่ชาย
  3. 不他们跟一起我去ฉันไม่ไปกับพวกเขา
  4. 吃饭一起我们吧กินข้าวด้วยกันเถอะ
  5. 想跟你一起我学习ฉันอยากเรียนหนังสือกับคุณ
  6. 昨天朋友我跟一起看电影了เมื่อวานฉันไปดูหนังกับเพื่อน

Cหาที่ผิดแล้วแก้ให้ถูก

แต่ละประโยคมีที่ผิดหนึ่งจุด เขียนประโยคที่ถูกต้อง

  1. 我去商店跟妈妈一起。ฉันจะไปร้านค้ากับแม่
  2. 我们吃饭一起吧。กินข้าวด้วยกันเถอะ
  3. 我跟他们一起不去。ฉันไม่ไปกับพวกเขา
  4. 我妈妈一起去医院。ฉันจะไปโรงพยาบาลกับแม่
  5. 你想跟我们吃饭一起吗？คุณอยากกินข้าวกับพวกเราไหม
