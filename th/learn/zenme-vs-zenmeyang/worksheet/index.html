怎么 / 怎么样 · ไวยากรณ์ HSK 1
ชื่อ วันที่

Aเลือก 怎么 หรือ 怎么样

เติม 怎么 หรือ 怎么样 ในช่องว่าง คำแปลภาษาไทยบอกความหมายของประโยค

  1. 明天天气？（怎么 / 怎么样）พรุ่งนี้อากาศจะเป็นยังไง
  2. 你不吃饭？（怎么 / 怎么样）ทำไมคุณไม่กินข้าว
  3. 你的新老师？（怎么 / 怎么样）ครูคนใหม่ของคุณเป็นคนยังไง
  4. 她还不睡觉？（怎么 / 怎么样）ทำไมเธอยังไม่เข้านอนอีก
  5. 我们明天去商店，？（怎么 / 怎么样）พรุ่งนี้เราไปร้านค้ากัน ดีไหม
  6. 你知道我的名字？（怎么 / 怎么样）ทำไมคุณถึงรู้ชื่อฉัน
  7. 这本书？（怎么 / 怎么样）หนังสือเล่มนี้ดีไหม
  8. 你今天不上班？（怎么 / 怎么样）ทำไมวันนี้คุณไม่ไปทำงาน
  9. 你们都不说话？（怎么 / 怎么样）ทำไมพวกคุณไม่มีใครพูดอะไรเลย

Bเรียงคำให้เป็นประโยค

เขียนคำทั้งหมดให้เป็นประโยคที่ถูกต้องหนึ่งประโยค

  1. 学校怎么你去คุณไปโรงเรียนยังไง
  2. 名字你的怎么写中文ชื่อภาษาจีนของคุณเขียนยังไง
  3. 那个怎么样饭店的菜อาหารร้านนั้นเป็นยังไง
  4. 睡觉怎么你没有还ทำไมคุณยังไม่เข้านอนอีก
  5. 我们怎么样晚上去中国菜吃เย็นนี้เราไปกินอาหารจีนกัน ดีไหม
  6. 了你怎么妈妈แม่ เป็นอะไรไป

Cหาที่ผิดแล้วแก้ให้ถูก

แต่ละประโยคมีที่ผิดหนึ่งจุด เขียนประโยคที่ถูกต้อง

  1. 这个苹果怎么？แอปเปิลลูกนี้ดีไหม
  2. 你怎么样不喝水？ทำไมคุณไม่ดื่มน้ำเลย
  3. 你去怎么商店？คุณจะไปร้านค้ายังไง
  4. 我们下午去看电影，怎么？บ่ายนี้เราไปดูหนังกัน ดีไหม
  5. 你的汉语老师怎么样吗？ครูภาษาจีนของคุณเป็นคนยังไง
