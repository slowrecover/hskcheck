只要……就 · ไวยากรณ์ HSK 3
ชื่อ วันที่

Aเลือก 只要 หรือ 只有

เติม 只要 หรือ 只有 ในช่องว่าง ดูคำว่า 就 หรือ 才 ในส่วนที่สอง

  1. 你来，我就很高兴。（只要 / 只有）ขอแค่คุณมา ฉันก็ดีใจแล้ว
  2. 做完作业，你才能看电视。（只要 / 只有）ต้องทำการบ้านเสร็จก่อน คุณถึงจะดูทีวีได้
  3. 天气好，我们就去爬山。（只要 / 只有）ขอแค่อากาศดี พวกเราก็จะไปปีนเขา
  4. 每天复习，你才能记住这些字。（只要 / 只有）ต้องทบทวนทุกวันเท่านั้น คุณถึงจะจำตัวอักษรเหล่านี้ได้
  5. 不忙，她就去看妈妈。（只要 / 只有）เมื่อไรที่ไม่ยุ่ง เธอก็ไปหาแม่
  6. 他同意，我们才能去。（只要 / 只有）เขาต้องตกลงก่อน พวกเราถึงจะไปได้
  7. 你说得慢一点儿，我就能听懂。（只要 / 只有）ขอแค่คุณพูดช้าลงหน่อย ฉันก็ฟังเข้าใจ
  8. 到了周末，他才有时间。（只要 / 只有）เขามีเวลาแค่ตอนสุดสัปดาห์เท่านั้น

Bเรียงคำให้เป็นประโยค

เขียนคำทั้งหมดให้เป็นประโยคที่ถูกต้องหนึ่งประโยค

  1. 只要你就想去去吧ขอแค่คุณอยากไป ก็ไปเถอะ
  2. 只要不下雨就我们去ขอแค่ฝนไม่ตก พวกเราก็จะไป
  3. 只要有时间我就看书เมื่อไรที่มีเวลา ฉันก็อ่านหนังสือ
  4. 只要你认真就能考好ขอแค่คุณตั้งใจ ก็จะสอบได้ดี
  5. 只有才他来了我们能开始เขาต้องมาก่อน พวกเราถึงจะเริ่มได้

Cหาที่ผิดแล้วแก้ให้ถูก

แต่ละประโยคมีที่ผิดหนึ่งจุด เขียนประโยคที่ถูกต้อง

  1. 只要你认真学，才能学好。ขอแค่คุณตั้งใจเรียน ก็จะเรียนได้ดี
  2. 只要天气好，就我们去。ขอแค่อากาศดี พวกเราก็จะไป
  3. 只有星期天，他就在家。เขาอยู่บ้านแค่วันอาทิตย์เท่านั้น
  4. 只要明天不忙，我去就看你。ขอแค่พรุ่งนี้ไม่ยุ่ง ฉันก็จะไปหาคุณ
