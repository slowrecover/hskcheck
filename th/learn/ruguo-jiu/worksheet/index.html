ชื่อ วันที่

Aเลือก 如果 因为 หรือ 虽然

เติม 如果 因为 หรือ 虽然 ในช่องว่าง ดูส่วนที่สองของประโยคและคำแปลภาษาไทย

  1. 明天天气不好，我们就在家看电视。（如果 / 因为 / 虽然）ถ้าพรุ่งนี้อากาศไม่ดี พวกเราจะอยู่บ้านดูทีวี
  2. 他生病了，所以今天没有来上课。（如果 / 因为 / 虽然）เขาป่วย วันนี้เลยไม่ได้มาเรียน
  3. 这件衣服很漂亮，但是太贵了。（如果 / 因为 / 虽然）เสื้อตัวนี้สวย แต่แพงเกินไป
  4. 你不喜欢，就别买了。（如果 / 因为 / 虽然）ถ้าไม่ชอบก็อย่าซื้อเลย
  5. 明天你有时间，就来我家吃饭吧。（如果 / 因为 / 虽然）ถ้าพรุ่งนี้คุณว่าง มากินข้าวที่บ้านฉันสิ
  6. 我很累，但是我还要工作。（如果 / 因为 / 虽然）ถึงฉันจะเหนื่อย แต่ก็ยังต้องทำงาน
  7. 路上车很多，所以我来晚了。（如果 / 因为 / 虽然）รถบนถนนเยอะมาก ฉันเลยมาสาย
  8. 我是你，我就不去。（如果 / 因为 / 虽然）ถ้าฉันเป็นคุณ ฉันจะไม่ไป

Bเรียงคำให้เป็นประโยค

เขียนคำทั้งหมดให้เป็นประโยคที่ถูกต้องหนึ่งประโยค

  1. 如果太贵就我不买了ถ้าแพงเกินไป ฉันก็ไม่ซื้อแล้ว
  2. 如果你就饿了先吃吧ถ้าคุณหิวก็กินก่อนเลย
  3. 如果他来我就走ถ้าเขามา ฉันก็จะไป
  4. 的话有问题如果就问老师ถ้ามีคำถามก็ถามครูนะ
  5. 就会如果你多练习说得更好ถ้าคุณฝึกมากขึ้น ก็จะพูดได้ดีขึ้น
  6. 明天如果不冷就我们去公园ถ้าพรุ่งนี้ไม่หนาว พวกเราก็ไปสวนสาธารณะกัน

Cหาที่ผิดแล้วแก้ให้ถูก

แต่ละประโยคมีที่ผิดหนึ่งจุด เขียนประโยคที่ถูกต้อง

  1. 如果你不去，就我不去。ถ้าคุณไม่ไป ฉันก็ไม่ไป
  2. 我就去，如果你去。ฉันจะไปถ้าคุณไป
  3. 如果你累了，我们休息就一下。ถ้าคุณเหนื่อย พวกเราก็พักกันสักหน่อย
  4. 如果你不吃早饭，会就饿。ถ้าคุณไม่กินข้าวเช้า ก็จะหิว
  5. 我们就去爬山，如果明天天气好。ถ้าพรุ่งนี้อากาศดี พวกเราจะไปเดินขึ้นเขากัน
