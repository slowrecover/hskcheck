除了……以外 · ไวยากรณ์ HSK 3
ชื่อ วันที่

Aเลือก 都 หรือ 还

เติม 都 หรือ 还 ในช่องว่าง คำแปลภาษาไทยหมายถึง "ยกเว้น" หรือ "นอกจาก...แล้วยัง"

  1. 除了爸爸，我们去过中国。（都 / 还）พวกเราเคยไปจีนกันหมด ยกเว้นพ่อ
  2. 除了苹果以外，我买了香蕉。（都 / 还）นอกจากแอปเปิลแล้ว ฉันยังซื้อกล้วยด้วย
  3. 除了星期六，我每天要上班。（都 / 还）ฉันต้องไปทำงานทุกวัน ยกเว้นวันเสาร์
  4. 除了唱歌，她喜欢跳舞。（都 / 还）นอกจากร้องเพลงแล้ว เธอยังชอบเต้นด้วย
  5. 除了这件衣服，别的我不喜欢。（都 / 还）นอกจากเสื้อตัวนี้แล้ว ตัวอื่นฉันไม่ชอบเลย
  6. 除了打扫房间以外，我洗了衣服。（都 / 还）นอกจากทำความสะอาดห้องแล้ว ฉันยังซักผ้าด้วย
  7. 除了一个问题以外，别的问题他回答对了。（都 / 还）เขาตอบถูกทุกข้อ ยกเว้นข้อเดียว
  8. 除了汉语，你学什么？（都 / 还）นอกจากภาษาจีนแล้ว คุณยังเรียนอะไรอีก

Bเรียงคำให้เป็นประโยค

เขียนคำทั้งหมดให้เป็นประโยคที่ถูกต้องหนึ่งประโยค

  1. 除了下雨天每天她都跑步เธอวิ่งทุกวัน ยกเว้นวันที่ฝนตก
  2. 除了米饭我还买了面包นอกจากข้าวแล้ว ฉันยังซื้อขนมปังด้วย
  3. 除了中国你还去过哪儿นอกจากจีนแล้ว คุณเคยไปที่ไหนอีก
  4. 除了我都不认识大家他ไม่มีใครรู้จักเขาเลย นอกจากฉัน

Cหาที่ผิดแล้วแก้ให้ถูก

แต่ละประโยคมีที่ผิดหนึ่งจุด เขียนประโยคที่ถูกต้อง

  1. 除了妹妹以外，我们还吃过饭了。พวกเรากินข้าวกันหมดแล้ว ยกเว้นน้องสาว
  2. 除了牛奶，我都买了鸡蛋。นอกจากนมแล้ว ฉันยังซื้อไข่ด้วย
  3. 除了周末，他每天还很忙。เขายุ่งทุกวัน ยกเว้นวันเสาร์อาทิตย์
  4. 除了喝茶以外，我都喜欢喝咖啡。นอกจากชาแล้ว ฉันก็ชอบกาแฟด้วย
  5. 除了妈妈，都我们喜欢吃鱼。พวกเราชอบกินปลากันทุกคน ยกเว้นแม่
