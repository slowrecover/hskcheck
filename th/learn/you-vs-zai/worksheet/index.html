又 vs 再 · ไวยากรณ์ HSK 3
ชื่อ วันที่

Aเลือก 又 หรือ 再

เติม 又 หรือ 再 ในช่องว่าง คำแปลภาษาไทยบอกว่าการทำซ้ำเกิดขึ้นไปแล้วหรือยัง

  1. 他上个星期来过，昨天来了。（又 / 再）สัปดาห์ที่แล้วเขามาที่นี่ เมื่อวานก็มาอีกแล้ว
  2. 这个字我没有看清楚，请你写一遍。（又 / 再）ตัวอักษรตัวนี้ฉันมองไม่ชัด ช่วยเขียนอีกครั้งได้ไหม
  3. 你怎么忘了带手机？（又 / 再）ทำไมคุณลืมเอามือถือมาอีกแล้ว
  4. 这个地方很漂亮，我想来一次。（又 / 再）ที่นี่สวยมาก ฉันอยากมาอีกสักครั้ง
  5. 下个月要放假了。（又 / 再）เดือนหน้าจะได้หยุดอีกแล้ว
  6. 别喝了，你已经喝了很多了。（又 / 再）อย่าดื่มอีกเลย คุณดื่มไปเยอะแล้ว
  7. 他今天没有吃早饭。（又 / 再）วันนี้เขาไม่ได้กินข้าวเช้าอีกแล้ว
  8. 我们下次去那家饭馆吧。（又 / 再）คราวหน้าเราไปร้านนั้นกันอีกนะ
  9. 外面下雨了。（又 / 再）ข้างนอกฝนตกอีกแล้ว
  10. 明天是星期一了，我不想上班。（又 / 再）พรุ่งนี้วันจันทร์อีกแล้ว ฉันไม่อยากไปทำงานเลย

Bเรียงคำให้เป็นประโยค

เขียนคำทั้งหมดให้เป็นประโยคที่ถูกต้องหนึ่งประโยค

  1. 又哥哥生病了พี่ชายป่วยอีกแล้ว
  2. 再一次请试ช่วยลองอีกครั้ง
  3. 想我再一次去ฉันอยากไปอีกสักครั้ง
  4. 又周末明天是了พรุ่งนี้เป็นวันหยุดสุดสัปดาห์อีกแล้ว
  5. 又没有他作业做เขาไม่ได้ทำการบ้านอีกแล้ว

Cหาที่ผิดแล้วแก้ให้ถูก

แต่ละประโยคมีที่ผิดหนึ่งจุด เขียนประโยคที่ถูกต้อง

  1. 他昨天再来了。เมื่อวานเขามาอีกแล้ว
  2. 我明天又来。พรุ่งนี้ฉันจะมาอีก
  3. 我再想吃一个。ฉันอยากกินอีกสักอัน
  4. 我的电脑昨天再坏了。เมื่อวานคอมพิวเตอร์ของฉันเสียอีกแล้ว
  5. 欢迎你们明年又来。ปีหน้ามาอีกนะ ยินดีต้อนรับเสมอ
