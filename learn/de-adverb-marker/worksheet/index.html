AChoose 的, 地 or 得

Write 的, 地 or 得 in each gap. The English tells you what the sentence means.

  1. 她高兴说：“谢谢你！”（的 / 地 / 得）She said happily, "Thank you!"
  2. 这是一个很好问题。（的 / 地 / 得）This is a very good question.
  3. 我哥哥跑很快。（的 / 地 / 得）My older brother runs fast.
  4. 你慢慢走，别跑。（的 / 地 / 得）Walk slowly, don't run.
  5. 我妈妈做菜很好吃。（的 / 地 / 得）The food my mum cooks is delicious.
  6. 她说汉语说很好。（的 / 地 / 得）She speaks Chinese very well.
  7. 他们非常快乐玩了一天。（的 / 地 / 得）They played very happily all day.
  8. 妈妈很快做好了饭。（的 / 地 / 得）Mum quickly made the meal.

BPut the words in order

Write the words as one correct sentence with 地.

  1. 慢慢地回家我们走We're walking home slowly.
  2. 笑了高兴地大家都Everyone laughed happily.
  3. 学习好好地我们要汉语We should study Chinese properly.
  4. 一天一天地孩子们长大了Day by day, the children grew up.
  5. 舒服地看电视他坐在椅子上He sat comfortably in the chair watching TV.
  6. 很快地跑了他过来He quickly ran over.

CFind and fix the mistake

Each sentence has one mistake. Write the correct sentence.

  1. 她高兴的说：“我很好！”She said happily, "I'm fine!"
  2. 孩子们唱歌快乐地。The children are singing happily.
  3. 他跑地很快。He runs fast.
  4. 这是一个很快乐地孩子。This is a very happy child.
  5. 请慢慢的说。Please speak slowly.
  6. 他快地跑过来了。He quickly ran over.
