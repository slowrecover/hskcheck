有点儿 / 一点儿 · HSK 1 grammar
Name Date

AChoose 有点儿 or 一点儿

Write 有点儿 or 一点儿 in each gap. The English tells you what the sentence means.

  1. 这个房间热。（有点儿 / 一点儿）This room is a bit hot.
  2. 这个太贵了，便宜吧。（有点儿 / 一点儿）This is too expensive. Make it a bit cheaper.
  3. 我想吃米饭。（有点儿 / 一点儿）I'd like to eat a little rice.
  4. 这件衣服小。（有点儿 / 一点儿）This top is a bit small.
  5. 今天也不热。（有点儿 / 一点儿）It's not hot at all today.
  6. 现在晚了，我们回家吧。（有点儿 / 一点儿）It's getting a bit late. Let's go home.
  7. 你早睡觉吧。（有点儿 / 一点儿）Go to bed a bit earlier.
  8. 我都不想吃。（有点儿 / 一点儿）I don't want to eat at all.
  9. 我想睡觉。（有点儿 / 一点儿）I'm a bit sleepy.
  10. 我爸爸会做中国菜。（有点儿 / 一点儿）My dad can cook a little Chinese food.

BPut the words in order

Write the words as one correct sentence.

  1. 贵手机有点儿这个This mobile phone is a bit expensive.
  2. 茶想一点儿我喝I'd like to drink a little tea.
  3. 忙不他也一点儿He isn't busy at all.
  4. 汉字我一点儿认识I know a few Chinese characters.
  5. 妈妈有点儿我想I miss my mum a bit.

CFind and fix the mistake

Each sentence has one mistake. Write the correct sentence.

  1. 这个菜一点儿贵。This dish is a bit expensive.
  2. 你多喝有点儿水。Drink a bit more water.
  3. 我们吃有点儿东西吧。Let's have a little something to eat.
  4. 这个电影有点儿也不好看。This film isn't good at all.
  5. 我今天一点儿忙。I'm a bit busy today.
