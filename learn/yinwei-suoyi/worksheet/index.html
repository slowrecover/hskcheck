因为……所以 · HSK 2 grammar
Name Date

AChoose 因为, 所以 or 为什么

Write 因为, 所以 or 为什么 in each gap. The English tells you what the sentence means.

  1. 今天很冷，所以我穿了很多衣服。（因为 / 所以 / 为什么）Because it's cold today, I'm wearing lots of clothes.
  2. 因为我没有钱，不能买这个手机。（因为 / 所以 / 为什么）I haven't got any money, so I can't buy this phone.
  3. 你不喜欢吃米饭？（因为 / 所以 / 为什么）Why don't you like rice?
  4. 我今天没有去上班，我生病了。（因为 / 所以 / 为什么）I didn't go to work today because I was ill.
  5. 外面下雨了，我们在家看电视吧。（因为 / 所以 / 为什么）It's raining outside, so let's watch TV at home.
  6. 你昨天没有来？（因为 / 所以 / 为什么）Why didn't you come yesterday?
  7. 这家饭馆的菜很好吃，我经常来。（因为 / 所以 / 为什么）The food at this restaurant is very good, so I come here often.
  8. 明天要考试，所以他今天晚上不看电视了。（因为 / 所以 / 为什么）He has an exam tomorrow, so he isn't watching TV this evening.

BPut the words in order

Write the words as one correct sentence. Use all the words.

  1. 所以因为太贵了我没有买It was too expensive, so I didn't buy it.
  2. 他为什么不高兴Why is he unhappy?
  3. 因为所以我生病了没有去学校I was ill, so I didn't go to school.
  4. 所以这个苹果很好吃我想再买一个因为This apple is delicious, so I want to buy another one.
  5. 我不想出去因为我很累I don't want to go out because I'm tired.
  6. 所以她是中国人因为她汉语说得很好She's Chinese, so she speaks Chinese very well.

CFind and fix the mistake

Each sentence has one mistake. Write the correct sentence.

  1. 所以今天下雨，因为我不出去了。It's raining today, so I'm not going out.
  2. 因为他很忙，他所以没有来。He was busy, so he didn't come.
  3. 我很累，因为我想睡觉。I'm tired, so I want to sleep.
  4. 我没有去上课，所以我生病了。I didn't go to class because I was ill.
  5. 他为什么不来？所以他太累了。Why isn't he coming? Because he's too tired.

因为……所以 · Answer key

A

  1. 因为
  2. 所以
  3. 为什么
  4. 因为
  5. 所以
  6. 为什么
  7. 所以
  8. 因为

B

  1. 因为太贵了，所以我没有买。
  2. 他为什么不高兴？ / 为什么他不高兴？
  3. 因为我生病了，所以没有去学校。 / 我因为生病了，所以没有去学校。 / 因为生病了，所以我没有去学校。
  4. 因为这个苹果很好吃，所以我想再买一个。
  5. 我不想出去，因为我很累。 / 因为我很累，我不想出去。
  6. 因为她是中国人，所以她汉语说得很好。

C

  1. 因为今天下雨，所以我不出去了。
  2. 因为他很忙，所以他没有来。 / 因为他很忙，所以没有来。
  3. 我很累，所以我想睡觉。
  4. 我没有去上课，因为我生病了。
  5. 他为什么不来？因为他太累了。
