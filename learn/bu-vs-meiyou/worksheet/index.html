不 / 没有 · HSK 1 grammar
Name Date

AChoose 不 or 没有

Write 不 or 没有 in each gap. The English tells you what the sentence means.

  1. 我昨天去学校。（不 / 没有）I didn't go to school yesterday.
  2. 他是中国人。（不 / 没有）He isn't Chinese.
  3. 我电脑。（不 / 没有）I don't have a computer.
  4. 明天我去商店。（不 / 没有）I'm not going to the shop tomorrow.
  5. 我还吃饭。（不 / 没有）I haven't eaten yet.
  6. 今天冷。（不 / 没有）It isn't cold today.
  7. 这个字我认识。（不 / 没有）I don't know this character.
  8. 上个星期他来上课。（不 / 没有）He didn't come to class last week.
  9. 我喜欢喝茶。（不 / 没有）I don't like tea.
  10. 你看了那个电影吗？我还看。（不 / 没有）Have you seen that film? I haven't seen it yet.

BPut the words in order

Write the words as one correct sentence.

  1. 去明天不医院我I'm not going to the hospital tomorrow.
  2. 钱没有我I don't have any money.
  3. 起床他没有还He hasn't got up yet.
  4. 忙今天不她She isn't busy today.
  5. 电视没有昨天看我们We didn't watch TV yesterday.

CFind and fix the mistake

Each sentence has one mistake. Write the correct sentence.

  1. 我不有哥哥。I don't have an older brother.
  2. 他昨天不来。He didn't come yesterday.
  3. 我没有吃饭了。I haven't eaten.
  4. 他没有是学生。He isn't a student.
  5. 我没有会说汉语。I can't speak Chinese.
